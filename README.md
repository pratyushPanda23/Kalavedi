# Kalavedi

Kalavedi is a full-stack web application developed to streamline the management of admissions, notices, and financial transactions for educational and cultural organizations. The platform provides a centralized interface for administrators and users to access important information and perform day-to-day operations efficiently.

## Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Mongoose
* Vite

## Features

* Admission application management
* Notice board system
* Transaction tracking and management
* Admin dashboard
* RESTful API architecture
* Responsive user interface

## Installation

```bash
git clone https://github.com/pratyushPanda23/Kalavedi.git
cd Kalavedi

# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

## Running the Project

```bash
# Start backend server
cd backend
npm start

# Start frontend
cd frontend
npm run dev
```
