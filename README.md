# Kalavedi 

Kalavedi is a full-stack web platform designed to streamline the management of admissions, notices, transactions, and administrative operations for cultural and educational organizations. The application provides a centralized system for students, administrators, and visitors to access important information and services.

##  Features

### 📢 Notice Management

* Display latest notices and announcements
* Real-time notice board updates
* Organized notice management system

### 📝 Admission Management

* Online admission application submission
* Application data storage and processing
* Structured application tracking

### 💰 Transaction Management

* Transaction record management
* Fee-related information handling
* Administrative transaction tracking

### 👨‍💼 Admin Dashboard

* Centralized administration panel
* Manage notices, applications, and transactions
* Secure administrative operations

### 🌐 Modern User Interface

* Responsive design
* Interactive React components
* User-friendly navigation
* Mobile-friendly experience

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/pratyushPanda23/Kalavedi.git
```

### Navigate to Project Directory

```bash
cd Kalavedi
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### Start Backend Server

```bash
cd ../backend
npm run dev
```

### Start Frontend

```bash
cd ../frontend
npm run dev
```

### Open Browser

```text
http://localhost:5173
```
